Python Programming MOOC 2025 - Solutions Repository
This repository documents my personal solutions for Part I of the [University of Helsinki's free massive open online course (MOOC) on Python Programming](https://programming-25.mooc.fi/). 
The MOOC is split into two courses: Introduction to Programming* (Part I) and Advanced Course in Programming (Part II). Each course contains seven sections with corresponding exercises.

We'll look at the following chapters:

click [All exercises](https://programming-25.mooc.fi/all-exercises)
